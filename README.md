# Globe Sprint

Browser-playable Unity WebGL build of Globe Sprint, built with Unity 6000.0.81f1.

Play: https://Jed0421.github.io/GlobeSprint/

## Controls
- Arrow keys or A/D: change lanes
- Space or W: jump
- S or Down: slide
- Touch: swipe to move, jump, or slide

## Publishing
This repository contains the exported game, including its custom loading screen. Enable GitHub Pages from the main branch and root folder.

The build files are decompressed so static hosting does not need custom Content-Encoding headers. Unity project source and generated editor caches are not included.
